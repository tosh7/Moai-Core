## 動作環境
Version: C++23

ビルドには CMake 3.20 以降が必要です。Ninja があればそれを、無ければ make を
使うので、どちらも事前に用意しなくて構いません。

## Elevator

待っているコールから行き先を判断する、単機のエレベーターです。

コア側はタイマーもスレッドも持ちません。`step()` が呼ばれるまで何も動かないので、
時間の進め方は呼び出し側が握ります。`Timer` から回しても、`CADisplayLink` に
合わせても、テストで一気に回しても構いません。

```cpp
#include "elevator.h"

Elevator elevator(10, 1);                 // 1階から10階まで。1階で待機

elevator.request({5, Direction::UP});     // 5階で上りボタンが押された
elevator.select_floor(8);                 // かごの中で8が押された

elevator.step();                          // 1回の呼び出しで1フロア進む
elevator.current_floor;                   // 2
elevator.is_selected(8);                  // 着くまで true
```

`request` はホールコール、つまり「何階でボタンが押されたか」と「その人がどちらへ
行きたいか」を記録します。同じ階の上りと下りは別のコールとして扱われます。建物の
範囲外は無視され、同じボタンを二度押しても何も変わりません。

`select_floor` はカーコール、つまりかごの中で選ばれた行き先を記録します。押した人は
既に乗っているので向きはありません。かごがその階に着けば、どちらへ走っていようと
そこで降ります。`is_selected` はその階のボタンがまだ点いているかを返すので、
行き先ボタンの表示はこれを見て描けます。

`step` はエレベーターを1フロア進めます。進行方向にコール（ホールでもかご内でも）が
残っている限りその向きを保ち、無くなったら反転します。そのため1階から5階へ向かう途中に3階のコールが入れば、
引き返さずに通り道で拾います。乗せるのは進行方向と一致するコールだけですが、
折り返す階では例外で、そこから先に用が無い以上、逆方向のコールもそこで乗せます。

未対応: ドアの開閉状態、地下階、複数台の配車。

## World

落ちて、ぶつかって、積み上がる円たちの入れ物です。

エレベーターと同じく時計を持ちません。`step(dt)` が決まった幅だけ時間を進め、
それを何回呼ぶかは呼び出し側が決めます。画面では見やすい速さで、テストでは一瞬で、
同じ動きを再現できます。刻み幅が固定なので結果も毎回同じで、同じ位置から落とせば
同じように積み上がります。

```cpp
#include "world.h"

World world(400, 800);                       // 400×800 の空間。床は y = 0
world.set_gravity({0, -1000});               // y は上向きなので下は負

int body = world.add_body({200, 700}, 20);   // 半径 20 の円

world.step(1.0f / 60);                       // 1 コマぶん時間を進める
world.position_of(body);                     // 今どこに描けばよいか
```

`add_body` はポインタではなく添字を返します。物体が増えても掴んだ相手を見失いません。
物体は円で、回転しません。長方形は後述の障害物として置きます。

`step` は重力を積分し、重なった物体を押し離し、ぶつかった勢いを跳ね返し、すべてを
壁の内側に留めます。重力で沈んで触れただけの組は跳ねず、本当にぶつかったときだけ
跳ねます。

`apply_radial_impulse` は、ある点の周囲にあるものを外向きに突き飛ばします。近いほど
強く飛ぶので、積み上がった山を叩いて散らすような動きになります。

### 障害物

任意の角度で置ける、物体が入り込めない長方形です。

```cpp
int shelf = world.add_obstacle({200, 300}, {100, 10}, 0);   // 幅 200、高さ 20、水平
world.move_obstacle(shelf, {200, 320}, 0.1f);               // 別の場所へ、少し傾けて

int mill = world.add_obstacle({200, 600}, {80, 8}, 0);
world.set_obstacle_spin(mill, 0);                           // 回れるようにする
world.obstacle_angle(mill);                                 // 今どこまで回ったか
```

障害物は物体とは別扱いです。落ちず、障害物同士でぶつからず、`body_count` にも
数えられません。物体は障害物の上に着地してそこに留まり、端を過ぎればそのまま
落ちます。奪われるのは障害物へ向かう成分だけで、面に沿った動きは残ります。
step の間に動かした障害物は、触れているものを一緒に運びます。

障害物は `set_obstacle_spin` を呼ぶまで、何をぶつけても動きません。棚や壁は
それでいいわけです。一度自由にすると、上に落ちたものが回し（中心から遠いほど
強く）、触れたものを弾き飛ばします。摩擦で少しずつ減速するので、叩けば回って、
やがて止まります。

### 抵抗と流れ

物体が動く「中身」です。

```cpp
world.set_drag(5);                                          // 水。既定の 0 は空気

int jet = world.add_flow({200, 0}, {0, 600}, 400, 40);      // 床から上へ 600、高さ 400、幅 40
world.set_flow(jet, 1);                                     // 0 で止まり 1 で全開。次に呼ぶまで保持
```

抵抗は毎秒、物体の速さを一定の割合だけ削ります。そのため濃いものの中を落ちる
物体はそれ以上速くならず、重力 ÷ 抵抗 の速さで一定に沈みます。

流れは、中身そのものが動いている柱です。根元が一番強く、届く距離と幅の端で
0 になります。抵抗は「静止」ではなく「中身の速さ」に向けて物体を引き寄せるので、
止まった水は物体を遅くし、動いている水は物体を運びます。抵抗が 0 なら、流れは
何も運べません。

### 持つ

```cpp
world.hold_body(body);                     // 物理の外へ。ホストの手の中に
world.move_body(body, finger);             // ちょうどここへ
world.release_body(body, {300, 0});        // 物理に戻し、この速さで動き出す
```

持たれた物体には重力も抵抗も流れも効かず、障害物や壁からも押し戻されません。
ホストが置いた場所がそのまま位置になります。ほかの物体からは壁と同じように
ぶつかる相手として残ります。指で何かを引きずるとき、ペグに刺さった輪などに。

未対応: 物体ごとの質量や材質、ジョイント、障害物を駆動するもの（与えた回転は
減るだけです）。

## Blower

吹き戻しです。息を吹き込むとほどけて伸び、やめると巻き戻ります。

```cpp
#include "blower.h"

Blower blower(200);                 // 全部伸びたら 200

blower.set_breath(0.7f);            // マイクから。0〜1、次に呼ぶまで保持
blower.step(1.0f / 120);            // 1 コマぶん時間を進める
blower.extension();                 // 今どこまで伸びているか。0〜200
```

中身はバネです。息が押し、紙の巻きグセが戻し、摩擦が止める。一定の息で吹けば
それに見合った長さで止まり（半分の息で半分、全力で全長）、やめれば少し跳ねて
巻き戻ります。両端では止まります。

コアは音を一切扱いません。マイクを読んで音量を息の強さに直すのはホストの仕事で、
絵文字プールが加速度センサーから重力を渡すのと同じ関係です。

未対応: 息と声の区別、先端のしなり。

## VoiceChanger

声のピッチを流れたまま変えます。名探偵コナンの蝶ネクタイ型変声機です。

```cpp
#include "voice_changer.h"

VoiceChanger changer(48000, 1024);   // ホストのサンプルレートと、1024 サンプルの窓

changer.set_pitch(12);               // 1 オクターブ上。-12 で下、0 でそのまま
changer.process(in, out, count);     // ホストがバッファを受け取るたびに
```

Blower と違って、音そのものがコアを通ります。サンプルが入ってサンプルが出る。
バッファの大きさはホストのオーディオユニット次第で構いません。マイクとスピーカーは
ホストのままです。出力は入力より窓 1 枚ぶん遅れ、1024 サンプル・48 kHz なら約 21 ms。
ホストが聞く遅延はこれです。

中身は短時間フーリエ変換の上の phase vocoder です。フレームごとに窓を掛けて変換し、
各ビンをシフトの比率の位置へ移す。移した先の位相は、その成分の本当の速さ
（前フレームからの位相の進みから測る）で進めるので、ビンの間にある音も狙った場所に
届き、両脇に散りません。

`fft.h` がその下の変換で、in-place の radix-2 Cooley–Tukey を自由関数 2 つで
持っています。他に使うものが出てきたときのためにも。

未対応: フォルマントの据え置き（今は声を上げると小さい人、下げると大きい人の声になる）、
オーディオスレッド向けの確保なし処理。

## WaterGame

ウォーターゲーム（輪投げ）です。水の入ったケースに輪が漂い、床に 2 つのポンプ、
輪を入れるペグがあります。水は World が担当します。

```cpp
#include "water_game.h"

WaterGame game(400, 800);

int left = game.add_jet({100, 0});            // 床のポンプ
int peg  = game.add_peg({200, 300}, 200);     // 先端が 300、高さ 200
int ring = game.add_ring({120, 700}, 20, 12); // 外径 20、穴 12

game.pump(left);                              // 1 回押す。勢いはすぐ消える
game.set_down({0.3f, -1});                    // 傾き。向きだけを使う
game.step(1.0f / 120);

game.ring_on_peg(ring);                       // 刺さっているペグ。無ければ -1
game.rings_on(peg);                           // スコア
```

輪は水の中のようにゆっくり沈みます。ボタンを押すとポンプから水が噴き出して、
上にあるものを持ち上げ、0.5 秒ほどで消えます。押しっぱなしにしても、1 回押したのと
同じです。先端が穴の中に入る形でペグの上に降りてきた輪は捕まり、ペグを滑り降りて、
先に入っている輪の上に乗ります。縁で乗った輪は滑り落ちます。

水の重さやポンプの強さはゲームが決めます。ホストが伝えるのは、下がどちらかと、
ボタンがいつ押されたかだけです。

未対応: ペグから輪が抜けること、垂直でないペグ、刺さった輪がほかの輪とぶつからなく
なること（今はペグの上でも外径の円としてぶつかります）。

## ビルド方法
.a ファイルを作るには以下を実行します。
1. このリポジトリを clone する
2. `sh build.sh` を実行する

`build/ios/libmoai.a` が出力されます。

このリポジトリは Swift package でもあるため、Xcode や他の `Package.swift` から
そのまま依存に追加できます。

## テスト方法
`sh test.sh` を実行します。ソースと `tests/` をまとめてビルドして実行し、
何件のチェックが通ったかを表示します。失敗があれば非ゼロで終了します。
